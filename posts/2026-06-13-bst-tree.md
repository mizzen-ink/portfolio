## 定义

BST（Binary Search Tree）又称二叉搜索树或二叉排序树，具有以下性质：

1. 若左子树非空，则左子树上所有节点的值均小于根节点的值
2. 若右子树非空，则右子树上所有节点的值均大于根节点的值
3. 左、右子树也都是二叉搜索树
4. 不允许键值重复
5. 对其进行中序遍历，得到递增的有序序列

## 基本结构

```cpp
struct BSTNode {
    int key;
    BSTNode* left;
    BSTNode* right;
    
    BSTNode(int val) : key(val), left(nullptr), right(nullptr) {}
};
```

## 查找操作

```cpp
BSTNode* search(BSTNode* root, int key) {
    if (!root || root->key == key) return root;
    if (key < root->key) return search(root->left, key);
    else return search(root->right, key);
}
```

**时间复杂度**：平均 O(log n)，最坏 O(n)（退化为链表）

## 插入操作

```cpp
BSTNode* insert(BSTNode* root, int key) {
    if (!root) return new BSTNode(key);
    if (key < root->key)
        root->left = insert(root->left, key);
    else if (key > root->key)
        root->right = insert(root->right, key);
    return root;
}
```

## 删除操作

删除分三种情况：

| 情况 | 操作 |
|-----|------|
| 叶子节点 | 直接删除 |
| 单子树 | 子节点替换 |
| 双子树 | 找前驱/后继替换 |

```cpp
BSTNode* minNode(BSTNode* node) {
    while (node->left) node = node->left;
    return node;
}

BSTNode* remove(BSTNode* root, int key) {
    if (!root) return nullptr;
    
    if (key < root->key)
        root->left = remove(root->left, key);
    else if (key > root->key)
        root->right = remove(root->right, key);
    else {
        if (!root->left) {
            BSTNode* temp = root->right;
            delete root;
            return temp;
        }
        if (!root->right) {
            BSTNode* temp = root->left;
            delete root;
            return temp;
        }
        BSTNode* temp = minNode(root->right);
        root->key = temp->key;
        root->right = remove(root->right, temp->key);
    }
    return root;
}
```

## BST vs 其他树结构

| 结构 | 平均查找 | 最坏查找 | 特点 |
|-----|---------|---------|------|
| BST | O(log n) | O(n) | 可能退化 |
| AVL | O(log n) | O(log n) | 严格平衡 |
| 红黑树 | O(log n) | O(log n) | 近似平衡 |

## 总结

BST 是理解更复杂平衡树（AVL、红黑树、B树）的基础。它的核心思想"左小右大"简单而优雅，但在极端情况下会退化为链表。实际工程中更常用红黑树或 AVL 树来解决退化的平衡问题。
